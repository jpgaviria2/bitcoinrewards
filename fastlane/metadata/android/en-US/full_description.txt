Rewards NFC Display is an open-source Android companion app for the Bitcoin Rewards BTCPay Server plugin.

It is designed for in-store tablets and counters:

• Display BTCPay-hosted rewards pages
• Scan customer Lightning-address QR codes natively
• Save the scan for the next Square order reward
• Pair with BTCPay using login QR/code flow
• Support NFC display/tap workflows
• Avoid browser camera permission issues

The app does not include merchant-specific defaults. Configure your own BTCPay Server URL and store ID after installation.
